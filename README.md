# Lokele-English New Testament Dataset

A verse-level parallel corpus of the **Lokele New Testament (1958)** and the **World English Bible (WEBUS)**, collected from Bible.com. The goal is to provide a transparent, reproducible resource for Lokele language research and AI development.

## Dataset

| Language | Translation                             | Bible.com Version |
| -------- | --------------------------------------- | ----------------- |
| Lokele   | Nouveau Testament in Kele/Lokele (1958) | `1496` (`NTKE58`) |
| English  | World English Bible (WEBUS)             | `206` (`WEBUS`)   |

The corpus covers all 27 New Testament books.

Each JSONL record contains:

```json
{
  "id": "MAT.1.1",
  "book": "Matthew",
  "chapter": 1,
  "verse": 1,
  "lokele": "...",
  "english": "..."
}
```

Verse IDs follow the `BOOK.CHAPTER.VERSE` format.

## Extraction and Validation

The dataset was collected using Scrapy, Playwright, and BeautifulSoup.

The current validation reports:

* 7,919 verse records
* 7,919 unique IDs
* No duplicate IDs, empty translations, malformed JSON, or alignment errors

See `validate_nt_dataset.py` and `nt_validation_report.json` for validation details.

## Missing Verses

Some verses are absent from the published Lokele source on Bible.com. Confirmed omissions are documented in the book-level `*_missing.json` reports.

The project does not fabricate missing translations or replace them with machine-generated text or another Bible version.
